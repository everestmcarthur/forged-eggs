# 🔥 Forge Eggs

The most comprehensive collection of game server, application, and service eggs for Forge Panel (compatible with Pelican and Pterodactyl panels).

**690 eggs** across 207 categories — every egg ever made for Pterodactyl, Pelican, and community sources, deduplicated and organized.

## Sources

This repository consolidates eggs from:
- [pelican-eggs](https://github.com/pelican-eggs) — Official Pelican eggs
- [Ptero-Eggs](https://github.com/Ptero-Eggs/game-eggs) — Community game eggs
- [DEVBenSon/pterodactyl-eggs](https://github.com/DEVBenSon/pterodactyl-eggs) — Custom & public eggs
- Individual pelican-eggs category repos (steamcmd, standalone, minecraft, etc.)

## How to Import an Egg

1. Download the `.json` egg file you need
2. In your Forge Panel admin, go to **Eggs** section
3. Click **Import Egg**
4. Select the downloaded JSON file
5. Assign it to a nest (create one if needed)
